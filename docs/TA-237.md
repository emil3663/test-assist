### TA-237 — Check for Updates confirmation does not anchor to the Check for Updates control

- **Phase:** 3
- **Priority:** P3
- **Suggested labels:** `bug`, `ux`
- **Problem it solves:** Running Check for Updates (UPD-12, which otherwise
  passes — it reaches GitHub and reports correctly) opens its result dialog
  partway down the screen instead of anchored near the button that triggered
  it (`test-assist-1789290085 Update confirmation.png`), which is jarring on
  a large or multi-monitor desktop where the dialog can appear far from
  where the user is looking.
- **Scope:** Position the confirmation dialog relative to the control that
  opened it (or to the launcher/editor window, whichever this app's other
  dialogs already anchor to) rather than at a default screen-centered or
  OS-chosen position.
- **Deliverables:** The dialog fix.
- **Acceptance criteria:** Triggering Check for Updates opens its result
  next to the control that triggered it.
- **Dependencies:** None.
